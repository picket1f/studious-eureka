# studious-eureka

A simple HTML/CSS/JavaScript calculator app.

## Features
- Basic arithmetic operations: add, subtract, multiply, and divide
- Decimal support
- Clear, delete, and sign toggle
- Keyboard support
- Responsive, dark-themed UI

## Run it locally
Open `index.html` in a browser.

## Project files
- `index.html` — calculator markup, styling, and logic

## Demo
This project is a lightweight single-page calculator built with plain HTML, CSS, and JavaScript.
